# lxl-low-code-platform-backend

Generated by **fastapi-deck** using the `standard` layout with database `sqlite`.

> Requires **Python 3.10+** (the generated code uses modern type syntax).

## Stack

- FastAPI (SQLite)
- JWT authentication (python-jose + passlib/bcrypt)
- CORS middleware, pydantic-settings typed config (`app/config.py` or `app/core/config.py`)

## Setup

```bash
python -m venv venv
# Windows (PowerShell): .\venv\Scripts\activate
# Windows (Command Prompt): venv\Scripts\activate
pip install -r requirements.txt
```

Copy `.env.example` to `.env` and adjust values.

## 数据库迁移（Alembic）

表结构由 Alembic 管理，应用启动时**不再**自动建表（`create_all` 已移除）。

```bash
# 首次部署 / 拉取代码后：把数据库升级到最新版本
python -m alembic upgrade head

# 修改 app/models 后：生成迁移脚本并应用
python -m alembic revision --autogenerate -m "add phone to users"
python -m alembic upgrade head

# 回滚一个版本
python -m alembic downgrade -1
```

- 迁移脚本位于 `migrations/versions/`，**需要提交到仓库**。
- 数据库连接复用 `app/config.py` 的配置，`alembic.ini` 里不再单独配置 URL。
- 用 Docker 时：`docker compose exec api alembic upgrade head`。

## Run

```bash
python -m alembic upgrade head   # 先建/更新表结构
uvicorn app.main:app --reload
```

Open http://localhost:8000/docs for the interactive Swagger UI.

## CI/CD

GitHub Actions + docker compose，流水线定义在 [.github/workflows/ci-cd.yml](.github/workflows/ci-cd.yml)。
代码主仓在 Gitee，同时镜像到 GitHub 触发构建；镜像推送到 GHCR。

```bash
# 本地等价的检查项
venv/Scripts/python.exe -m ruff check app migrations
venv/Scripts/python.exe -m pytest
venv/Scripts/python.exe -m alembic upgrade head && venv/Scripts/python.exe -m alembic check
```

服务器接入、凭据配置、发布与回滚步骤见 [docs/ci-cd.md](docs/ci-cd.md)。
